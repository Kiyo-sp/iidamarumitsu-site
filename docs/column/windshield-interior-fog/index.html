ワイパーを動かしても取れない曇り――フロントガラスの内側

更新 2026-11-25

ぬれた上着のまま車に乗った日、ワイパーが端まできれいに払ったのに、前がまだ白い。水が付いているのは、同じガラスの反対側です。

車内の湿った空気が冷たいガラスに触れると、細かな水滴が付いて曇りになります。対策の基本は、除湿した空気をガラスへ送ること。エアコンフィルターは空気の通り道でごみなどを捕らえますが、除湿そのものを行う部品ではありません。

ガラスの外側につく雨粒と、内側にできる曇りでは対処が違います。外側ならワイパーの状態、内側なら曇り取りやエアコンの風の出方を確認します。

部品を確認するとき

曇り取りの操作は車種によって異なります。取扱説明書でフロントガラスの曇り取り機能を確認し、視界が十分に確保できてから走行してください。
