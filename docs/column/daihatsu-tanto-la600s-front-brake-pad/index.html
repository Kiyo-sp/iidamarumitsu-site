年式で品番が分かれている

3代目タントの2WD（LA600S）のフロントブレーキパッドは、当社の出荷実績で見ると、2015年式を境に品番が分かれています。2014〜2015年式の車にはTN760M（とTN638M）、2015〜2019年式の車にはTN792Mを出荷していました。

2015年式はどちらの品番も出ているので、年式だけでは決められません。同じLA600Sでも、製造時期やグレードによってブレーキの仕様が違うためです。ご注文の前に、車台番号でどちらに当たるかを確認させてください。

交換を考えたいサイン

  • ブレーキを踏んだときに「キーキー」と金属がこすれるような音がする（パッドの残りが少なくなると音で知らせる仕組みのものがあります）
  • 車検や点検でパッドの残量が少ないと言われた
  • ブレーキの効きが以前より甘く感じる

ブレーキは安全に直結する部品です。音や違和感があるときは、そのまま乗り続けずに点検を受けてください。パッドがなくなるまで使うと、ディスクローターまで傷めてしまい、交換する部品が増えます。

一緒に交換されることが多い部品

当社では、フロントパッドと同じ日にエアーエレメントやタイロッドエンドカバー、ボールジョイントカバーが出荷されることがありました。車検整備のときに、足回りのゴム部品やエアーエレメントとまとめて交換されているケースが多いと考えられます。

ご注文のときに伝えてほしいこと

  • 車検証の車台番号（LA600S-から始まる番号）
  • 車検証の初度登録年月
  • 純正相当のパッドか、ほかの銘柄を希望するか

当社の実績はトキコ（TN品番）のパッドが中心ですが、ほかのメーカーのパッドも取り寄せできます。

ブレーキ・足回りなどの安全に関わる部品です。品番は必ず車検証の車台番号でご確認ください。
