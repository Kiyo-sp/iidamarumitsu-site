# 写真を記事に入れる

1. 写真のファイルの場所と、どの記事に入れるかを確認する（記事は `site/src/content/column/` のファイル名）。
2. 何が写っているかを担当者に確認し、説明文を決める（例: 「トキコ TN792M の実物」）。品番を書く場合は、その記事の実績にある品番だけ。
3. `cd site` → `npm run add-photo -- "<写真のパス>" <URL名> "<説明>"`
   - 自動で向きを直し、縮小し、撮影場所などの情報を消して保存します。
4. `npm run check` → `npm run preview-drafts` で確認してもらい、OK なら publish-site で公開。
- 同じ部品の写真を別の記事でも使いたいときは、その記事の `photos` に同じ `src` を書き足してよい。
- お客様の車のナンバーや車検証、人の顔が写っている写真は使わない。
